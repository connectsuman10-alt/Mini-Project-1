# Distraction-Free YouTube Clone 🎥

A simple distraction-free version of YouTube built completely using HTML.

## 📌 About the Project

This is my first web development project, created as a beginner while learning HTML.
The main idea behind this project was to design a clean and minimal YouTube interface focused only on content without unnecessary distractions.

## 🚀 Features

* Clean and minimal UI
* Simple YouTube-inspired layout
* Beginner-friendly project
* Built entirely with HTML

## 🛠️ Technologies Used

* HTML5

## 📚 What I Learned

Through this project, I learned:

* Basic HTML structure
* Creating layouts using HTML
* Working with images, links, and sections
* Building a real-world inspired webpage
